Arduino analog input basics

Read a changing voltage and account for the ADC range and reference of the exact board.

An analog-to-digital converter (ADC) maps a voltage within its input range into a digital code. On a development board, the usable input voltage, resolution, reference source, pin mapping, and conversion behavior depend on the exact processor and board design. Never assume a generic conversion scale from a different Arduino model.

Potentiometer example concept

A potentiometer wired between a suitable supply and ground can provide a variable wiper voltage. The wiper can connect to an analog input only if the full voltage range remains within that input's documented limits. Connect grounds as specified by the board manufacturer. Avoid loose wires and never connect a signal above the allowed input range.

Sketch outline

In a board-compatible sketch, configure or use the documented analog input pin, read its ADC value using the supported API, and print the raw reading over the serial interface. Add averaging or filtering only when the application needs it; filtering cannot correct an electrically unsafe input or poor reference.

Interpret what you measure

  • Look up the ADC resolution, reference voltage, attenuation settings if any, and allowable input range for the selected board.
  • Use a meter to confirm the wiper voltage before connecting it to the input.
  • Expect noise and small changes from source impedance, wiring, grounding, and converter characteristics.
  • Do not convert raw counts to volts using an assumed constant unless verified for the hardware and configuration.

For voltage scaling, understand the limitations described in the divider draft; for an ESP32-specific safety checklist, see checking signals before ESP32 inputs.
