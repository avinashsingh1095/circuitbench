Arduino analog input basics

Read a potentiometer voltage and distinguish ADC counts from a calibrated voltage measurement.

An ADC maps an analog input voltage to a digital count. On the classic Arduino UNO R3, analogRead() returns a 10-bit value from 0 to 1023; the default analog reference is related to the board supply. The actual reference voltage is not guaranteed to be exactly 5.000 V, so count-to-voltage conversion using 5 V is an estimate. Other Arduino boards can differ in resolution, reference, allowed input voltage, pin names, and API behavior.

UNO R3 sketch

const byte analogPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  const int raw = analogRead(analogPin);
  const float estimatedVolts = raw * (5.0 / 1023.0);
  Serial.print("ADC: ");
  Serial.print(raw);
  Serial.print("  estimated V: ");
  Serial.println(estimatedVolts, 3);
  delay(250);
}

The estimate assumes a 5.0 V reference. To improve voltage accuracy, measure the actual reference/supply appropriately and account for ADC error, noise, and source impedance. A numerical display is not a calibrated instrument reading.

Worked reading

If the sketch prints a raw count of 512 and the measured ADC reference is 5.00 V, endpoint scaling estimates 512 × 5.00/1023 = 2.502 V (about 2.50 V). If you instead assume exactly 5.00 V but the actual reference is 4.85 V, the same count corresponds to about 2.427 V. This shows why the code's 5.0 V constant is only an estimate; use the measured/reference value and the board's ADC specifications when accuracy matters.

Wire and troubleshoot safely

  1. Power down while wiring. Connect potentiometer outer terminals to the board's documented supply and ground; connect the wiper to A0.
  2. Before attaching A0, use a meter to check the wiper remains within the board input range throughout its adjustment.
  3. Select Arduino UNO Rev3 and the correct port, upload the sketch, then open Serial Monitor at 9600 baud.
  4. Slowly turn the potentiometer. A reading that is stuck at an endpoint can indicate swapped/missing ground, an incorrectly placed wiper wire, or a short; power down before changing connections.
  5. Small fluctuations are normal in many setups. Improve wiring and grounding before adding averaging; software filtering cannot make an overvoltage safe.

For voltage scaling concepts, read voltage dividers and loading. For an ESP32-specific warning, see checking signals before ESP32 inputs.
