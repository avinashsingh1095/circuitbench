When not to use a divider alone

A divider is not a voltage regulator and does not clamp transients. It can be a poor power source because load current changes its output. Before connecting a microcontroller input, check that device's normal input range, absolute maximum, protection requirements, source impedance, and transient behavior. Use a buffer or purpose-designed interface where the input specification requires it.
