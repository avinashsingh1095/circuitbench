Connecting an LED to an Arduino output

Plan a simple indicator circuit with a current-limiting resistor and board-specific checks.

A common indicator circuit connects a digital output through a series resistor and LED to the board's ground, or uses the opposite polarity where supported by the board. The LED conducts in one direction; identify its anode and cathode from the component documentation rather than relying on package appearance alone.

Choose parts before wiring

Read the LED datasheet for forward voltage and a suitable operating current. Estimate R = (Vpin − Vf) ÷ I, using the board's actual logic level and current in amperes. Then confirm the resistor value and power dissipation. A standard-value calculation is only a starting point.

Respect the microcontroller limits

Check the exact Arduino board's documentation for per-pin source/sink current, total port current, and absolute maximum conditions. Do not treat an absolute maximum as a normal operating target. Some boards have an onboard LED connected to a particular pin, but pin assignments differ among models.

Upload and observe

  1. Disconnect USB or other power while wiring.
  2. Build the series circuit on a breadboard, checking polarity and avoiding adjacent-row shorts.
  3. Connect the board using its documented voltage and ground references.
  4. Upload a minimal blink example for the selected board and pin.
  5. If behavior is unexpected, disconnect power and inspect the wiring before changing code.

Use the LED resistor calculator for a single-LED estimate. It cannot determine whether a selected board pin is capable of driving that load.

Hardware-specific: Board revisions and processors differ. Verify pin names, logic voltage, and electrical limits in the official documentation for the exact model.

Review notes

Test this procedure on specifically named Arduino boards, with board documentation citations, before publication.
