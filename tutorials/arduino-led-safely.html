Connecting an LED to an Arduino output

Use a series resistor, identify the LED polarity, and check the exact board's electrical limits.

A digital output can control a small indicator LED through a current-limiting resistor. The resistor and LED are in series; the resistor limits current. Identify anode/cathode from the LED documentation and verify the target board logic voltage and pin ratings before building.

Illustrative resistor calculation

For an Arduino UNO R3-style 5 V logic output and an example LED assumed to have Vf = 2.0 V at the chosen current, a 10 mA target gives R = (5 − 2)/0.010 = 300 Ω. Choosing a common 330 Ω resistor estimates (5 − 2)/330 = 9.1 mA. Its ideal dissipation is I²R ≈ 0.027 W. These are estimates using assumed LED voltage and nominal output voltage, not a particular LED datasheet or guaranteed output voltage. Check LED current and board total-current limits; use the exact board/LED documentation.

Minimal Arduino sketch

const byte ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(500);
  digitalWrite(ledPin, LOW);
  delay(500);
}

This uses the Arduino language's documented pinMode and digitalWrite APIs and assumes a board package that maps digital pin 8. Select the correct board and port in Arduino IDE; the sketch does not verify hardware wiring.

Build and troubleshoot

  1. Disconnect board power before wiring. Connect pin 8 to the resistor, resistor to LED anode, and LED cathode to GND (or follow the documented polarity markings).
  2. Inspect breadboard rows for shorts and confirm LED polarity, then reconnect USB and upload.
  3. If it does not blink, disconnect power, check the selected board/port and pin mapping, verify resistor continuity and LED direction, and inspect the ground connection.
  4. If the LED is unexpectedly dim or the board resets, disconnect and review current demand, wiring, and the component specifications before retrying.

Use the LED resistor calculator for a single-LED estimate; it cannot validate an Arduino pin's capability.

Hardware-specific: This example is scoped to an UNO R3-style 5 V board. Other Arduino boards may use different logic voltage, pin mapping, and current limits.
