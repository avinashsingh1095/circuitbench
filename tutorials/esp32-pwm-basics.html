ESP32 PWM fundamentals

Set pulse frequency and duty cycle with LEDC, while treating the output as a digital waveform.

Pulse-width modulation (PWM) switches a digital output between low and high. Duty cycle is the fraction of a period spent high. At 5 kHz, one period is 1/5000 = 200 Î¼s. At 25% duty, the signal is high for 50 Î¼s and low for 150 Î¼s. For a 3.3 V logic waveform, the ideal time-average is 3.3 × 0.25 = 0.825 V; this is not a steady analog output, and actual load response depends on the circuit.

Arduino-ESP32 core 3.x example

This sketch uses the pin-based LEDC API introduced in Arduino-ESP32 3.x. Choose a GPIO permitted by your exact board/module; GPIO 18 is only an example pin.

const uint8_t pwmPin = 18;
const uint32_t pwmFrequency = 5000;
const uint8_t pwmResolution = 8;

void setup() {
  Serial.begin(115200);
  if (!ledcAttach(pwmPin, pwmFrequency, pwmResolution)) {
    Serial.println("LEDC attach failed; check pin and core version.");
    while (true) {
      delay(1000);
    }
  }
  ledcWrite(pwmPin, 64); // 64/255 is approximately 25%
}

void loop() {
}

With 8-bit resolution, duty values range from 0 through 255; 64/255 is approximately 25.1%. For other core versions, use the matching official API documentation rather than assuming this sketch is compatible.

Output and load checks

  1. Start with no load. Select the correct ESP32 board/core version and build the sketch.
  2. Use an oscilloscope or suitable logic analyzer to verify the pin's frequency, amplitude, and duty. A multimeter may display an average that depends on its design and waveform.
  3. Check the chip and board GPIO electrical limits before attaching a driver.
  4. Use an appropriately rated transistor/MOSFET or driver for motors and higher-power LEDs; include inductive-load protection such as a correctly selected flyback path where the circuit requires it.
  5. If output setup fails, check the installed Arduino-ESP32 core version and whether the chosen pin is available on that board. If the board resets under load, remove the load and review driver wiring and supply capacity.

A GPIO is not a power output. Read checking signals before ESP32 inputs before connecting external signals.

Do not connect motors or high-power loads directly to an ESP32 GPIO. Power down while wiring and verify device limits in the exact board/chip documentation.
