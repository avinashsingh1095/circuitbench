ESP32 PWM fundamentals

Use pulse-width modulation to control average energy delivered to a suitable load.

Pulse-width modulation (PWM) switches a digital output between logic states and changes the fraction of each period spent high. This fraction is the duty cycle. For a simple resistive load and a sufficiently fast switching rate, the average voltage can be approximated from supply voltage and duty cycle, but the waveform remains a sequence of pulses; PWM is not automatically a true analog output.

Hardware and API differ

ESP32 chip generations, board cores, and software frameworks expose PWM differently. Consult the documentation for the actual chip, board package, and framework version. Confirm supported channels, frequency/resolution tradeoffs, GPIO suitability, and pin restrictions. Avoid pin assumptions copied from another board.

Drive the load appropriately

A GPIO is a logic output, not a general-purpose power driver. Check its electrical limits. A motor, high-power LED, or other substantial load needs an appropriate external driver stage, power supply, flyback or transient handling where required, and a common reference or isolation strategy suitable to the circuit. Never connect an inductive load directly to a GPIO without a designed interface.

Basic validation sequence

  1. Start with an unloaded output and a scope or suitable logic instrument to verify frequency and duty behavior.
  2. Check the output pin and load ratings before adding a driver.
  3. Change one parameter at a time and observe the actual waveform.
  4. Check heating, supply behavior, and resets during controlled load tests.

This is a concept overview, not a ready-to-flash sketch: exact API calls are intentionally omitted until a specific supported ESP32 board and framework version are selected. Review the ESP32 input safety draft before connecting external signals.
