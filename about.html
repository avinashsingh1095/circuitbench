About

A small, practical electronics workbench

CircuitBench brings common circuit calculations and beginner-oriented electronics learning drafts together in a lightweight static website.

What you'll find

The calculators cover Ohm's law, a single-LED series resistor estimate, an unloaded two-resistor divider, four-band resistor decoding, and basic resistive DC power. Each tool states its units and important assumptions. The tutorials introduce circuit fundamentals, Arduino, ESP32, and troubleshooting topics.

How to use the material

Calculator outputs are idealized results, not a substitute for checking component datasheets, board documentation, actual circuit conditions, or applicable safety requirements. The ten tutorials are clearly marked drafts requiring factual review and practical testing before publication or use.

How the site works

CircuitBench uses plain HTML, CSS, and browser JavaScript. It has no site backend, database, sign-in, API key, advertising code, or third-party runtime library. A hosting provider may still process technical request data as described in that provider's own policies.
