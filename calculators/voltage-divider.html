Voltage divider calculator

Calculate the output at the junction of two resistors connected in series across a DC supply. The output is assumed to be unloaded.

From input to output node
From output node to ground

Enter values and select Calculate to see a result.

Formula and assumptions

With R₁ connected from the input to the output node and R₂ from that node to ground, the unloaded output is Vout = Vin × R₂ ÷ (R₁ + R₂). Series current is Vin ÷ (R₁ + R₂). The load is not included; a connected load changes the effective lower resistance and therefore the output.

A divider is not automatically a suitable power supply or a safe way to interface every signal. Consider load impedance, resistor tolerance, input protection, and the limits of the receiving circuit.

Worked example

For 5 V, R₁ = 1 kΩ, and R₂ = 10 kΩ, Vout = 5 × 10,000 ÷ 11,000 = about 4.545 V unloaded. Divider current is about 0.455 mA. A connected load will generally pull this voltage down.
